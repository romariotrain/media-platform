# Media Service

Реестр метаданных медиафайлов. Источник истины о состоянии каждого медиа-объекта.

## Порт

`:8081`

## Что делает

- Хранит метаданные: ID, тип (video/audio/file), статус, источник
- Управляет статусами через конечный автомат
- Публикует события об изменениях в Kafka
- Не обрабатывает файлы — только фиксирует состояние

## HTTP API

| Метод | Endpoint | Описание |
|-------|----------|----------|
| `POST` | `/media` | Создать запись о медиа |
| `GET` | `/media/{id}` | Получить медиа по ID |
| `PATCH` | `/media/{id}/status` | Изменить статус |
| `GET` | `/health` | Health check |

## Статусы медиа

```
uploaded → processing → ready
                     → failed
```

## Особенности

Этот сервис архитектурно отличается от остальных:
- Использует собственный Kafka Producer с retry и метриками
- Использует интерфейс `DomainEvent` вместо строковых типов событий
- Не слушает команды от оркестратора — работает самостоятельно
- Имеет in-memory реализацию репозитория для тестов

## Граница ответственности

Сервис не занимается загрузкой файлов, транскодированием, публикацией и квотами.
Он фиксирует состояние и метаданные. Изменения статусов происходят через события от других сервисов.

## БД таблицы

- `media` — метаданные (id, status, type, source)

## Ключевые файлы

- `service/change_status.go` — атомарная смена статуса + событие
- `kafka/producer.go` — кастомный producer с retry
- `repository/memory.go` — in-memory репозиторий для тестов
